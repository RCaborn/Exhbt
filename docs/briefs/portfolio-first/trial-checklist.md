# Trial checklist: the new portfolio

For Rory and Alex, before the switch goes on for everyone. Tick a box when it works. When it doesn't, write what you saw in the last column: the look you were in, what you pressed, what you expected.

**Before you start.** Sign in as an admin on a Premium account that has a few exhbts, one of them a draft. In development, open `/dev/portfolio-kind?kind=page` first; on the live site you opt in below. Use a second account on Free for the lines that say "on Free".

## On a laptop

| Done | Try this | What went wrong |
|---|---|---|
| ☐ | On the step builder press **Try the new portfolio**. You land on your page, not a form. | |
| ☐ | Type in each part of the hero: name, headline, intro. Reload. It is all still there. | |
| ☐ | Change the look to Studio and back to Exhbt. The page changes where it sits. | |
| ☐ | Add a section, then press Undo (or Ctrl+Z). It goes. | |
| ☐ | Drag a tile by its grip to a new place. Reload. The order held. | |
| ☐ | Hide a tile, then Show it from the hidden row. | |
| ☐ | Press the **Add tile**, then add an exhbt, write a title, and press "Your portfolio" to go back. Your title was kept. | |
| ☐ | Publish that exhbt (Premium). You come back to the portfolio, the tile says Live, and a note gives its link with Copy. | |
| ☐ | On Free, publish says the exhbt stays a draft only you can see, with a way back. | |
