# The person chooses how a per-job link reads

0001 gave every employer link a short random suffix so the company could not be guessed. Max users now choose per link:

- `alex.exhbt.co.uk/lloyds-x7k2`: the default. The company is readable but the address can't be guessed, so nobody can try other company names to see where someone applied.
- `alex.exhbt.co.uk/lloyds`: cleaner, and guessable. The editor says so when it's chosen.

Either way the page is never indexed by search engines, and the person can switch it off. Links stay a path on the person's host, never a further subdomain.
