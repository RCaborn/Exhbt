# Free hosts a small portfolio. Pro is the whole product.

The public name of the top consumer tier is Pro. The stored key stays `premium` (the database enum, the waitlist `interest` value, and the pricing anchor). Universities pay, and their students get Pro. Employers never pay and never need an account. Plus and Pro have no price yet. The waitlist stays.

Figures, and only here as the record of this decision. The code wins if they ever differ: `lib/entitlements.ts`.
