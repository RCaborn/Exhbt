# Design references

## awesome-design-md/

84 `DESIGN.md` files describing the design language of public sites, vendored from
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) at commit `fcc7028` (MIT, see `awesome-design-md/LICENSE`).

These are reference material, not active instructions. To use one, copy a brand's
`DESIGN.md` to the project root (or point the agent at it), e.g.:

```bash
cp design-references/awesome-design-md/linear.app/DESIGN.md ./DESIGN.md
```

To refresh: re-copy `design-md/` from the upstream repo.
